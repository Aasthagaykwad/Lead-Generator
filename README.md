# Student Lead Generator

An automated lead generation tool designed to help find students on LinkedIn and Instagram for pitching IT Courses.

## Features
- **Smart Web Scraping**: Automatically searches Google, Internshala, and local college directories for students in Nagpur (or custom locations).
- **Instagram & LinkedIn Support**: Extracts social media profiles so you can reach out directly.
- **Direct Messaging**: Click a single button to open WhatsApp, Instagram DM, or LinkedIn messages with a pre-filled template.
- **Dynamic Templates**: Create custom pitch templates that automatically insert the student's Name and College.
- **Lead Scoring**: Automatically ranks leads based on how relevant they are to IT courses (B.Tech, BCA, MCA, etc).

## Tech Stack
- **Frontend**: React (Vite), TailwindCSS, Lucide Icons
- **Backend**: FastAPI (Python), SQLite / PostgreSQL
- **Deployment**: Configured for Vercel (UI) and Render (API)

## Local Development
1. Clone the repository.
2. Run `start.bat` on Windows to start both the Frontend and Backend servers simultaneously.
3. Access the dashboard at `http://localhost:3000`.
